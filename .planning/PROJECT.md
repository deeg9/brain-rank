# NeuroCut — Neural A/B Testing for Content Creators

## What This Is

A neural A/B testing tool that lets content creators upload videos and get brain-activation-based engagement scores. The inference pipeline (TRIBE v2 on RunPod) is complete and live. This milestone focuses on auditing and consolidating the UI screens generated by Google Stitch, producing a clear spec to feed back into Stitch for final production-ready UI generation.

## Core Value

Send a video URL to a RunPod endpoint and get back per-segment brain activation scores as JSON — proving the model works, the pipeline is viable, and inference time is acceptable.

## Current Milestone: v1.1 UI Audit & Consolidation

**Goal:** Analyze 13 Google Stitch-generated UI screens, consolidate duplicates, define the canonical screen set, identify gaps, and produce a Stitch brief for final UI generation.

## Context

- TRIBE v2 is a Meta Research model (facebookresearch) for predicting brain activation from video/audio stimuli
- Licensed CC BY-NC-4.0 — fine for validation, commercial use needs separate arrangement later
- RunPod serverless endpoint is live and returning neural activation scores
- 13 UI screens exist in /Users/deeg/Downloads/NeuroCutStitchUI/ generated by Google Stitch
- Screens have significant overlap — multiple variants of the same flows from iterative Stitch generation
- Design system documented in NeuroCutStitchUI/neurocut_obsidian/DESIGN.md
- No frontend code exists yet in this repo — UI is purely HTML mockups from Stitch

## Constraints

- **No code output**: This milestone produces documentation/specs only, not implementation
- **Model license**: CC BY-NC-4.0 — non-commercial only for now
- **GPU requirement**: TRIBE v2 requires CUDA-capable GPU — RunPod A100/A40
- **Inference time**: ~12 minutes per 60s video — UX must handle long async processing
