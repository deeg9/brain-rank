The exact implementation per DES-05 and the routing locked decisions:

```typescript
import { createClient } from "@/lib/supabase/server";
import { redirect } from "next/navigation";
import { HeroOdyssey } from "@/components/hero/HeroOdyssey";

export default async function Home() {
  const supabase = await createClient();
  const {
    data: { user },
  } = await supabase.auth.getUser();

  if (user) redirect("/dashboard");

  return (
    <div data-landing className="min-h-screen bg-background">
      <HeroOdyssey />
    </div>
  );
}
```

Note: `HeroOdyssey` is a `"use client"` component, which is valid to import from a server component. The `data-landing` attribute on the wrapper div activates the grayscale token overrides from Task 1. The `bg-background` class will resolve to `#000000` inside `[data-landing]`.
