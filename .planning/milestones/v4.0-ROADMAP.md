## Milestone Goal

Transform NeuroCut from a private analysis tool into a public discovery platform with user identities, public/private analysis sharing, a neural-score-ranked discovery feed, and social engagement features.

## Key Accomplishments

1. **User Identity System** — Profiles table with citext usernames, auto-creation trigger, avatar upload with client-side resize, bio editing
2. **Public Profiles** — Public profile pages at /u/username with stats, public analyses grid, initials avatar fallback
3. **Privacy Controls** — Public/private toggle on analyses, shareable links with clipboard copy, 404 for non-owner private access
4. **Public Analysis View** — Full brain viewer, neural timeline, and metrics at /analysis/{id} without authentication
5. **Discovery Feed** — Browsable /discover page with neural score ranking, search, sort, and score filters
6. **Social Engagement** — View counts, bookmarks with optimistic UI, /bookmarks page
