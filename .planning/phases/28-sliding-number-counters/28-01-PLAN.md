Create `web/src/components/ui/SlidingNumber.tsx` — a reusable spring-animated number counter.

**Component API:**
```typescript
interface SlidingNumberProps {
  value: number;          // Target number to animate to
  suffix?: string;        // Optional suffix like "%" or "s"
  prefix?: string;        // Optional prefix like "$"
  decimals?: number;      // Decimal places (default 0)
  className?: string;     // Additional classes for the number text
  springConfig?: { stiffness?: number; damping?: number; mass?: number };
  triggerOnView?: boolean; // Whether to wait for viewport entry (default true)
}
```

**Implementation approach using Framer Motion useSpring + useTransform:**

1. Accept `value` prop. Use a `useRef` for the container element and Framer Motion's `useInView(ref, { once: true })` to detect viewport entry (when `triggerOnView` is true, which is the default).

2. Create a `motionValue` with `useMotionValue(0)` for the starting point. When the component mounts and is in view (or immediately if `triggerOnView=false`), animate using `useSpring` with config `{ stiffness: 75, damping: 15, mass: 0.5 }` (these defaults produce a visible overshoot-and-settle spring feel). Use a `useEffect` that calls `springValue.set(value)` when `isInView` becomes true or when `value` changes.

3. Use `useTransform(springValue, (latest) => ...)` to derive the display string — round to `decimals` places, prepend `prefix`, append `suffix`.

4. Render a `motion.span` that displays the transformed value. Use `useMotionValueEvent(displayValue, "change", ...)` to update a React state string that gets rendered. The component must inherit font styling from its parent (no hardcoded font classes) — just render the number text inside a `<span>` with the passed `className`.

5. Use `cn()` from `@/lib/utils` for class merging.

**Important details:**
- The component is `"use client"` (uses hooks and framer-motion).
- Export as named export: `export function SlidingNumber(...)`.
- The spring must produce VISIBLE overshoot — stiffness 75, damping 15 gives a nice bounce. Too high damping (>30) kills the spring feel.
- When `value` prop changes after initial animation, the spring should animate to the new value (not just on mount).
- Handle edge case: if `value` is 0, don't animate (already at target).
