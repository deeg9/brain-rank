<objective>
Replace the CPU-bound d3-color CSS string parsing (20,484 string allocations per segment change) with a 256-entry Uint8Array LUT built once at colormap change time. Update BrainHeatmapMesh to use DynamicDrawUsage and useFrame for GPU-synced buffer updates.

Purpose: Eliminate the primary rendering bottleneck -- d3-color parses 20K CSS strings per segment. The LUT reduces this to 20K array index lookups (orders of magnitude faster).
Output: Rewritten colormap.ts with LUT functions, updated BrainHeatmapMesh.tsx with useFrame/DynamicDrawUsage, unit tests.
</objective>
