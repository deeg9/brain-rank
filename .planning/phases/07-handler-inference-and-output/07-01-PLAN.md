    - Summary: overall = mean of all segment activation_scores, hook_score = mean of first 5 segments (first 10s), retention_score = mean of last 5 segments (last 10s), peak_second = start time of highest activation segment, peak_score = that segment's activation_score
    - If odd number of aligned segments, last unpaired segment forms its own 1-second window
    - raw_shape = list(predictions.shape) (original pre-alignment shape)
    - duration_seconds = len(segments) * SEGMENT_DURATION_S (from original TRIBE segments)
    - Logs "Job {job_id}: postprocessing — {n} aligned segments -> {m} output windows"
  </behavior>

Create src/postprocessor.py with a single public function:

```python
def postprocess(predictions: np.ndarray, segments: list, video_url: str, job_id: str) -> OutputSchema:
```

Implementation steps:
1. Import logging, numpy, Path. Import OutputSchema, Segment, RegionScores, Summary from src.schema. Import align_to_stimulus from src.region_mapping.temporal. Import compute_region_scores from src.region_mapping.scoring. Import SEGMENT_DURATION_S from src.region_mapping.constants.
2. Create logger = logging.getLogger("neurocut.postprocessor").
3. Load masks: `masks_path = Path(__file__).parent.parent / "data" / "region_masks.npz"`. Load with np.load, convert to dict of arrays.
4. Call `aligned = align_to_stimulus(predictions)` -- this drops first 5 segments.
5. Call `region_scores = compute_region_scores(aligned, masks)` -- returns dict[str, ndarray(n,)].
6. Build 2-second output windows by iterating in steps of 2 over aligned segments:
   - For indices i, i+1: average the two rows of aligned predictions for overall activation_score (mean of all 20484 vertices across both rows).
   - Average region_scores[region][i] and region_scores[region][i+1] for each region.
   - arousal = (attention_avg + emotional_processing_avg) / 2
   - valence = (reward_avg + social_cognition_avg) / 2
   - start = i * SEGMENT_DURATION_S (relative to aligned timeline, which starts at video second 0 after HRF correction)
   - end = start + 2.0 (or start + 1.0 for trailing odd segment)
   - Build Segment and RegionScores Pydantic objects.
7. Build Summary from the output_segments list.
8. Log "Job {job_id}: postprocessing complete — {len(output_segments)} windows"
9. Return OutputSchema(video_url=video_url, duration_seconds=len(segments)*SEGMENT_DURATION_S, segments=output_segments, summary=summary, raw_shape=list(predictions.shape)).
