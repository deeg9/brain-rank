Steps for the user:

   ```

3. Set your environment variables:

   ```
   chmod +x scripts/build_and_push.sh

6. Wait for push to complete (depends on upload speed -- image is ~12-15 GB)

7. The script will print the full image URL at the end. Copy it -- you need it for the next step.

**Expected output:** Something like `Successfully pushed: your-username/neurocut-worker:latest`

**If build fails:** Check Docker Desktop has enough disk space (needs ~30GB free for build cache + image). Also verify HF_TOKEN is set correctly.

  <action>
User creates RunPod serverless endpoint following docs/deployment_guide.md Steps 3-4.

Docker image is now on Docker Hub from Task 1.

Steps for the user:

1. Go to https://www.runpod.io/console/serverless

2. Click "+ New Endpoint"

3. Fill in the settings:
   - **Endpoint Name:** neurocut-worker
   - **Container Image:** (paste the Docker Hub image URL from Task 1)
   - **GPU:** Select "A40" (48GB, $0.35/hr). If unavailable, "A30" works too.
   - **Container Disk:** 20 GB
   - **Environment Variables:** Add `HF_TOKEN` with your Hugging Face token value
   - **Advanced Settings:**
     - Execution Timeout: 1200 (seconds) -- this is 20 minutes, needed because inference takes 10-13 min
     - Max Workers: 1
     - Active (Min) Workers: 0 (scale to zero -- no idle cost)
     - Enable FlashBoot if available
   - Click "Create Endpoint"

4. On the endpoint details page, copy the **Endpoint ID** (a string like "abc123def456")

5. Go to https://www.runpod.io/console/user/settings (Settings > API Keys)

6. Create a new API key or copy your existing one (starts with "rp_")

7. Save both values -- you need them for testing:
   ```
   export RUNPOD_API_KEY=rp_your-api-key
   export RUNPOD_ENDPOINT_ID=your-endpoint-id
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User machine -> Docker Hub | Docker credentials during login and push |
| User machine -> RunPod API | API key in Authorization header |
| RunPod -> Docker Hub | Image pull (public image, no auth needed) |
| RunPod container -> HuggingFace | HF_TOKEN for gated model downloads at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Information Disclosure | RunPod env vars | mitigate | HF_TOKEN set via RunPod web console (encrypted at rest by RunPod). Guide instructs user to use env vars, never hardcode in image. |
| T-08-06 | Information Disclosure | RUNPOD_API_KEY | mitigate | API key used only in local test script via env var. Never committed to git. .env is in .gitignore. |
| T-08-07 | Spoofing | Docker Hub image | accept | Public image acceptable for validation phase. No secrets baked in. Production should use private registry or RunPod's container registry. |
| T-08-08 | Denial of Service | RunPod endpoint | mitigate | Max Workers set to 1 to cap costs during validation. Scale-to-zero (Min Workers: 0) prevents idle charges. |
</threat_model>
