  <name>Task 1: Create LightningShader WebGL component</name>
  <files>web/src/components/hero/LightningShader.tsx</files>
  <action>
Create a React component that renders a full-size WebGL canvas with an animated lightning/electrical effect using a fragment shader.

**WebGL Detection and Fallback:**
- Before creating the WebGL context, check `canvas.getContext('webgl2') || canvas.getContext('webgl')`.
- If WebGL is unavailable, render a static CSS gradient fallback: a radial gradient from purple (#ba9eff at 20% opacity) to transparent, centered, on the #0e0e10 background. Use a `<div>` with the gradient as background instead of the canvas.
- Accept a `className` prop for positioning.

**Fragment Shader (GLSL):**
The shader implements fractal Brownian motion (FBM) lightning. Key elements:
- Uniforms: `u_time` (float, elapsed seconds), `u_resolution` (vec2, canvas size), `u_hue` (float, default 0.75 which is ~270/360 for purple), `u_intensity` (float, default 0.6), `u_speed` (float, default 1.6), `u_size` (float, default 2.0).
- Hash/noise function: `hash(vec2 p)` returning pseudo-random float.
- Value noise: `noise(vec2 p)` using bilinear interpolation of hash values.
- FBM: `fbm(vec2 p)` with 6 octaves, 0.5 amplitude decay, 2.0 frequency gain.
- Lightning calculation: Use FBM to distort UV coordinates, then compute intensity based on distance from distorted center line. Apply `pow()` for sharp falloff creating lightning bolt appearance.
- HSV to RGB conversion function for coloring based on `u_hue`.
- Final color: Mix background (#0e0e10 as vec3(0.055, 0.055, 0.063)) with lightning color using computed intensity.

**Vertex Shader:** Simple pass-through rendering a full-screen quad (two triangles from a single attribute-less draw using gl_VertexID or a simple position buffer).

**React Integration:**
- Use `useRef` for canvas element and WebGL context/program references.
- Use `useEffect` for WebGL setup (compile shaders, create program, set up geometry) and animation loop via `requestAnimationFrame`.
- Clean up on unmount: cancel animation frame, delete WebGL program/shaders, lose context.
- Handle canvas resize: listen to `ResizeObserver` on the canvas parent, update `u_resolution` uniform and canvas size. Use `devicePixelRatio` for crisp rendering but cap at 2 to avoid GPU strain.
- The component should be a `"use client"` component.
- Do NOT include any hue slider or interactive controls (production component, not a demo).

**Performance:**
- Use `requestAnimationFrame` for the render loop.
- Only update `u_time` uniform each frame (other uniforms set once on init).
- Canvas should have CSS `position: absolute; inset: 0; width: 100%; height: 100%`.
