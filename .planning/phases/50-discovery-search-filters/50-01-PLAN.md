**Filtering and sorting pipeline (useMemo):**
Create a `filteredAnalyses` useMemo that depends on [analyses, sortOption, debouncedSearch, scoreFilter]:

1. Start with full `analyses` array
2. **Search filter:** If debouncedSearch is non-empty, filter to items where `title` or `creator_username` includes the search term (case-insensitive)
3. **Score filter:** If scoreFilter !== "all", filter to items where `overall_score` >= parseInt(scoreFilter). Items with null score are excluded when a score filter is active.
4. **Sort:** Apply sort based on sortOption:
   - "score": overall_score descending, nulls last (existing behavior)
   - "newest": created_at descending (most recent first)
   - "oldest": created_at ascending
5. Return the filtered+sorted array

**Remove the existing hardcoded sort** (lines 84-89 in current file) since sorting is now handled by the useMemo pipeline.

**Update visibleAnalyses** to slice from `filteredAnalyses` instead of `analyses`.

**Reset visibleCount to PAGE_SIZE** whenever sortOption, debouncedSearch, or scoreFilter changes (useEffect).
