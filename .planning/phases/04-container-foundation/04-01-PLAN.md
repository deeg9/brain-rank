**Dockerfile structure (EXACT ORDER MATTERS):**

1. **Base image:** `FROM nvidia/cuda:12.4.1-cudnn-runtime-ubuntu22.04`

2. **Environment setup:**
   - `ENV DEBIAN_FRONTEND=noninteractive` (suppress apt prompts)
   - `ENV PYTHONUNBUFFERED=1` (RunPod log visibility)
   - `ARG HF_TOKEN` (build-time arg for optional model pre-download)
   - `ENV HF_TOKEN=${HF_TOKEN}` (runtime access to gated models — per CNTR-03)

3. **System dependencies (single RUN to minimize layers):**
   - `apt-get update && apt-get install -y --no-install-recommends python3.11 python3.11-venv python3.11-dev python3-pip ffmpeg git wget curl`
   - Set python3.11 as default: `update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.11 1 && update-alternatives --install /usr/bin/python python /usr/bin/python3.11 1`
   - Symlink pip: `ln -sf /usr/bin/pip3 /usr/bin/pip` (if needed)
   - Clean apt cache: `&& apt-get clean && rm -rf /var/lib/apt/lists/*`

4. **Pip upgrade:** `RUN pip install --no-cache-dir --upgrade pip setuptools wheel`

5. **PyTorch FIRST (CRITICAL — must be before TRIBE v2):**
   ```
   RUN pip install --no-cache-dir \
       torch==2.6.0+cu124 \
       torchvision==0.21.0+cu124 \
       torchaudio==2.6.0+cu124 \
       --index-url https://download.pytorch.org/whl/cu124
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build-time secrets | HF_TOKEN passed as ARG during docker build — visible in image layer history |
| Runtime env vars | HF_TOKEN passed at container runtime for gated model access |
| External code fetch | TRIBE v2 cloned from GitHub at build time — supply chain risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | Dockerfile ARG HF_TOKEN | mitigate | Use ARG (not ENV) for build-time token so it does not persist in final image layers. Document that --build-arg should only be used if pre-downloading models at build time. For runtime, pass via ENV at container start (RunPod endpoint config), never bake into image. |
| T-04-02 | Information Disclosure | verify_container.py | mitigate | Script checks HF_TOKEN presence but NEVER prints the token value. Only prints "set" or "not set" status. |
| T-04-03 | Tampering | git clone tribev2 | accept | TRIBE v2 is a public Meta Research repo. Pinning to a specific commit hash would improve supply chain security but adds maintenance burden. Acceptable risk for a validation project with CC BY-NC-4.0 license. |
| T-04-04 | Elevation of Privilege | Container runs as root | accept | ML inference containers commonly run as root for GPU access. RunPod workers run in isolated container environments. No user-facing network services in this container. Acceptable for serverless inference workload. |
</threat_model>
