Create src/text_renderer.py with a single public function:

```python
def render_text_card(text: str, style: str, job_id: str) -> Path:
```

Parameters:
- text: the user's text content (up to 500 chars)
- style: one of "billboard", "social_post", "general" (default to "general" if unknown)
- job_id: for temp file naming

Returns: Path to a saved PNG at /tmp/card_{job_id}.png (1280x720)

Use Pillow (PIL) which is already available from Phase 53's image_converter.

**Billboard template:**
- Background: dark gradient effect — fill with dark navy/charcoal (e.g., RGB 15, 15, 35) then draw a subtle radial-ish highlight in the center using a semi-transparent overlay rectangle
- Text: white, centered both horizontally and vertically
- Font: Pillow's default font loaded at large size via `ImageFont.truetype` with DejaVuSans (available in the Docker container at /usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf). Fallback to `ImageFont.load_default()` if not found.
- Font size: calculate dynamically — start at 72px, reduce until text fits within 1120px width (80px padding each side). Use `draw.textbbox` to measure.
- For multi-line: if text is longer than ~60 chars, wrap at word boundaries using textwrap.wrap with width ~30 chars, reduce font size to 56px.

**Social Post template:**
- Background: dark surface (RGB 20, 20, 30)
- Draw a "card" rectangle inset 80px from each edge, filled with slightly lighter color (RGB 35, 35, 50), with a 2px border line in a muted blue-gray (RGB 80, 80, 120)
- Text: white, centered inside the card area
- Font size: 48px, wrap at ~35 chars
- Add a small decorative line (4px tall, 60px wide, primary blue RGB 100, 130, 255) centered above the text block

**General template:**
- Background: solid dark (RGB 18, 18, 24)
- Text: light gray (RGB 220, 220, 230), centered
- Font size: 56px, wrap at ~32 chars
- Clean, minimal — just centered text on dark background

All templates:
- Output: Image.new("RGB", (1280, 720), bg_color)
- Save as PNG to /tmp/card_{job_id}.png
- Use textwrap.wrap for line breaking
- Calculate vertical centering based on total text block height
- Log the style and text length

Import textwrap from stdlib. Import PIL Image, ImageDraw, ImageFont.
