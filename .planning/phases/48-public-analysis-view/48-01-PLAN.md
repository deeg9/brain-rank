| Boundary | Description |
|----------|-------------|
| Public internet -> /analysis/[id] page | Unauthenticated users access analysis data |
| Server component -> Supabase | Server queries job data with is_public filter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48-01 | Information Disclosure | page.tsx data query | mitigate | Only return jobs where is_public=true AND status=completed. RLS on Supabase enforces at DB level. Query filters in server component as defense-in-depth. |
| T-48-02 | Information Disclosure | page.tsx video_url exposure | accept | video_url is part of job.results which is passed to client. No video playback occurs but URL is in data. Acceptable for public analyses -- user opted in to public visibility. |
| T-48-03 | Denial of Service | BrainViewer 3D rendering | accept | Client-side only, same as authenticated view. No server cost. |
| T-48-04 | Spoofing | /analysis/[id] with arbitrary IDs | mitigate | notFound() returned for non-existent or non-public IDs. No information leakage about private job existence. |
</threat_model>
