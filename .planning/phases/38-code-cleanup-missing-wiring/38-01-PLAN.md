    2. **Fetch job:** Query `supabase.from('jobs').select('*').eq('id', id).single()`.
       Return 404 if not found.

    3. **Verify ownership:** Check `job.user_id === user.id`. Return 404 if mismatch (avoid leaking existence).

    4. **Check status:** Only allow retry on `failed` jobs. Return 400 with `{ error: 'Job is not in failed state' }`
       if status is not 'failed'.

    5. **Reset job:** Update job to `{ status: 'pending', error_message: null, runpod_id: null, results: null }`.

    6. **Re-dispatch to RunPod:** Follow the exact pattern from POST /api/jobs/route.ts:
       - Read RUNPOD_API_KEY and RUNPOD_ENDPOINT_ID from env
       - POST to `https://api.runpod.ai/v2/${endpointId}/run` with `{ input: { video_url: job.video_url } }`
       - On success: update job with `{ runpod_id: runpodResponse.id, status: 'processing' }`
       - On RunPod failure: update job to `{ status: 'failed', error_message: 'Failed to start inference' }`,
         return 502

    7. Return the updated job as JSON with status 200.

    Follow the same error handling pattern as the existing routes (try/catch, return 500 for unexpected errors).
    Use `{ params }: { params: Promise<{ id: string }> }` for the route params (Next.js 15 async params).
