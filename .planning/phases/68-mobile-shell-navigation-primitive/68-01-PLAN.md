<objective>
Make the application shell (AppShell + TopBar) mobile-aware without changing the desktop layout. This establishes the responsive chrome primitives that every downstream v8.0 phase depends on.

Purpose: Downstream phases (69–72) cannot touch page content on mobile until the shell itself stops overflowing the 390px iPhone 15 viewport. This plan delivers the minimum mechanical transform — hide desktop-only chrome behind `hidden md:flex`, expose a hamburger behind `md:hidden`, scale the AppShell gutters responsively, and stub the MobileNavSheet component so Plan 02 can implement its behavior without blocking this plan's verification.

Output:
- `web/src/components/layout/AppShell.tsx` — responsive padding `p-4 md:p-8`
- `web/src/components/layout/TopBar.tsx` — hamburger visible on mobile only, existing right-side cluster visible on desktop only, wired to (stubbed) MobileNavSheet state
- `web/src/components/layout/MobileNavSheet.tsx` — new stub component accepting `{ open, onClose }` props, renders nothing when closed, renders a minimal closable shell when open (full behavior lands in Plan 02)
- iPhone 15 (390×844) and desktop (1280×800) Playwright screenshots proving the change
</objective>
