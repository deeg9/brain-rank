      7. Logout button: calls `onLogout` prop, `text-error` on interaction state, ≥44px tall, rendered as `<button>` not a link.
    - Dismiss paths (all three must work and all three call `onClose`):
      * X button click.
      * Backdrop click (click on backdrop div — stop propagation inside the sheet body so taps inside don't close).
      * ESC key (attach a `keydown` listener on `document` while `open === true`, remove on close/unmount).
    - Auto-close on navigation: when a nav link is tapped, call `onClose` after navigation starts (use Next.js `<Link>` with an `onClick={onClose}` handler so the sheet closes as we navigate away).
    - Focus management:
      * On transition from closed → open: after mount, focus the close (X) button. (Using the close button, not the first nav link, keeps keyboard users from accidentally activating a link before they've seen the sheet.)
      * On transition from open → closed: parent handles focus restoration to hamburger (Task 2 wires this via ref). No action needed inside MobileNavSheet for restoration.
      * Focus trap is optional/simple — a minimal implementation (keydown Tab/Shift+Tab wrapping between first and last focusable elements) is acceptable per CONTEXT.md discretion, but if time-constrained, document the trade-off in SUMMARY.
    - Animation:
      * CSS transition on transform: `translate-y-[-8px] opacity-0` when mounted, `translate-y-0 opacity-100` after a `requestAnimationFrame` tick to trigger the transition. Duration `200ms`, easing `ease-out` per CONTEXT.md discretion.
      * Backdrop animates `opacity-0` → `opacity-100` on the same timing.
      * On close, set the reverse states, then call `onClose` after the transition ends (use `transitionend` or a setTimeout matching duration).
      * Simpler acceptable alternative: use Framer Motion (already project dep per CONTEXT) — `AnimatePresence` + `motion.div` with `initial/animate/exit` props. Pick whichever keeps the file under ~180 lines.
    - Scroll lock while open: set `document.body.style.overflow = "hidden"` on open, restore on close.
    - Reduced motion: respect `prefers-reduced-motion: reduce` — if set, skip the animation (enter/exit is instant). Either via `window.matchMedia` or via Tailwind's `motion-reduce:` variant on the transition classes.
    - Visibility boundary: the entire component's root element uses `md:hidden` so even if TopBar accidentally flips `open={true}` at desktop widths, nothing renders visually.
