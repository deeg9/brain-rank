Create `web/src/app/api/username/check/route.ts` with a GET handler:

1. Import `NextRequest`, `NextResponse` from `next/server` and `createClient` from `@/lib/supabase/server`
2. Define `RESERVED_USERNAMES` as a `Set` containing exactly these 20 entries: `admin`, `api`, `settings`, `help`, `support`, `discover`, `profile`, `login`, `signup`, `dashboard`, `upload`, `results`, `about`, `terms`, `privacy`, `billing`, `account`, `user`, `users`, `public`
3. Authenticate with `supabase.auth.getUser()` -- return 401 if not authenticated (prevents bot enumeration per locked decision)
4. Read `username` from `request.nextUrl.searchParams.get('username')` and lowercase it
5. Validate: if missing, return `{ available: false, reason: 'Username required' }`
6. Validate length: if `< 3` or `> 20`, return `{ available: false, reason: 'Must be 3-20 characters' }`
7. Validate format: if not matching `/^[a-z0-9_]+$/`, return `{ available: false, reason: 'Only lowercase letters, numbers, and underscores' }`
8. Check reserved: if in `RESERVED_USERNAMES`, return `{ available: false, reason: 'This username is reserved' }`
9. Query database: `supabase.from('profiles').select('id').eq('username', username).neq('id', user.id).maybeSingle()`
10. Return `{ available: !data, reason: data ? 'Username is already taken' : null }`

Create `web/src/app/api/profile/route.ts` with a PATCH handler:

1. Same imports as above
2. Authenticate -- return 401 if not authenticated
3. Parse body: `const { username } = await request.json() as { username?: string }`
4. If username is provided (not undefined/null), validate server-side:
   - Lowercase it
   - Check length 3-20 and format `/^[a-z0-9_]+$/`
   - Return 400 with `{ error: 'Invalid username format' }` if invalid
5. Update profile: `supabase.from('profiles').update({ username: username?.toLowerCase() ?? null }).eq('id', user.id).select().single()`
6. Handle errors:
   - If `error.code === '23505'`, return 409 with `{ error: 'Username already taken' }`
   - Other errors: return 500 with `{ error: 'Failed to update profile' }`
7. Return updated profile data as JSON (200)
