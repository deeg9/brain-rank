**Button.tsx** - Three variants matching Stitch:
```tsx
"use client";
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: "primary" | "secondary" | "ghost";
  size?: "sm" | "md" | "lg";
  loading?: boolean;
  children: React.ReactNode;
}
```
- `primary` variant: `neural-gradient text-on-surface font-headline font-bold rounded-lg hover:opacity-90 active:scale-[0.98] transition-all shadow-lg shadow-primary/20`
- `secondary` variant: `bg-surface-container-highest text-on-surface font-semibold rounded-lg hover:bg-surface-bright transition-colors ghost-border`
- `ghost` variant: `text-on-surface-variant hover:text-on-surface transition-colors`
- Sizes: `sm` = `px-3 py-1.5 text-sm`, `md` = `px-6 py-2.5 text-sm`, `lg` = `px-8 py-4 text-base w-full`
- Disabled state: `bg-surface-container-highest text-on-surface-variant cursor-not-allowed opacity-60` (overrides variant)
- Loading state: Show a spinning icon and "Loading..." text, disable clicks

**Input.tsx** - Bottom-border input matching Stitch login form:
```tsx
interface InputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  label?: string;
  error?: string;
}
```
- Container: `space-y-2`
- Label: `text-xs font-bold font-headline uppercase tracking-widest text-on-surface-variant ml-1`
- Input: `w-full bg-surface-container-low border-b-2 border-outline-variant focus:border-secondary focus:ring-0 px-4 py-3 text-on-surface placeholder:text-outline transition-all duration-300 outline-none rounded-none` (rounded-none because these are bottom-border-only inputs)
- Error: `text-error text-xs mt-1` shown below input when error prop provided

**Card.tsx** - Elevated card container:
```tsx
interface CardProps {
```
