```typescript
interface WaveLoaderProps {
  bars?: number;       // default 10
  message?: string;    // optional text below wave (e.g., "Analyzing neural patterns...")
  className?: string;  // container className override
}
```

Implementation details:
- Render `bars` vertical bars inside a flex container with `items-end` and `gap-1`
- Each bar is a `motion.div` with fixed width (~3px) and animated `scaleY` using Framer Motion's `animate` prop
- Animation: `scaleY` keyframes cycling between `[0.3, 1, 0.3]` with `repeat: Infinity`, `duration: ~1.2s`, `ease: "easeInOut"`
- Stagger: Each bar gets a `delay` of `index * 0.1` seconds to create the wave propagation effect
- Color: Alternate bars between primary (#ba9eff) and secondary (#5af8fb) using modulo — even bars get `bg-primary`, odd bars get `bg-secondary` (use Tailwind classes that map to these values, which are `bg-primary` and `bg-secondary` in the NeuroCut design system)
- Bar height container: ~48px tall (`h-12`)
- Each bar base height: full height of container, with scaleY controlling visible portion
- Add subtle opacity variation: bars further from center slightly more transparent for depth
- If `message` prop provided, render it below the bars as `text-xs text-on-surface-variant` with a `mt-2`
- Use `cn()` from `@/lib/utils` for className merging
- "use client" directive at top (Framer Motion requires client component)
