Create `web/src/app/discover/page.tsx` -- this is a **client component** (needs useState for pagination state).

**Why client component:** The "Load More" button requires client-side state to track the current page offset and append new results. The initial data load and subsequent loads both use the Supabase anon client from `@/lib/supabase/client`.

**File structure:**

1. `"use client"` directive at top
2. Import `{ createClient }` from `@/lib/supabase/client` (browser client, not server)
3. Import `{ useState, useEffect, useCallback }` from `react`
4. Import `{ DiscoverCard, type DiscoverAnalysis }` from `./DiscoverCard`

**Constants:**
- `const PAGE_SIZE = 20`

**Component `DiscoverPage`:**

State:
- `analyses: DiscoverAnalysis[]` -- accumulated results
- `loading: boolean` -- true during fetch
- `hasMore: boolean` -- whether more pages exist
- `initialLoad: boolean` -- true until first fetch completes (for skeleton/empty distinction)

**`fetchAnalyses` function** (useCallback, depends on analyses.length):
- `setLoading(true)`
- Create supabase client: `const supabase = createClient()`
- Query: `supabase.from('jobs').select('id, title, video_url, results, created_at, user_id').eq('is_public', true).eq('status', 'completed').order('created_at', { ascending: false }).range(analyses.length, analyses.length + PAGE_SIZE - 1)`
- Note: We cannot sort by overall_score in Supabase since it's inside a JSONB `results` column. Instead, fetch all and sort client-side, OR fetch by created_at and sort client-side. Use the simpler approach: fetch by created_at, then after fetching all data for the page, sort the accumulated array by overall_score descending.

Actually, better approach for v4.0: fetch ALL public completed jobs (likely < 100 per roadmap success criteria), sort client-side by overall_score. This avoids complex pagination-with-sort issues. Implement as:

- On mount (useEffect with empty deps), fetch ALL public completed analyses in one query (no range/limit -- roadmap says "up to 100 public analyses")
- Query: `supabase.from('jobs').select('id, title, video_url, results, created_at, user_id').eq('is_public', true).eq('status', 'completed')`
- For each job, fetch the creator profile: do a second query `supabase.from('profiles').select('id, username, avatar_url').in('id', uniqueUserIds)` where uniqueUserIds is the set of distinct user_id values from the jobs
- Map jobs to `DiscoverAnalysis[]`: extract `overall_score` from `(job.results as Record<string, unknown> | null)?.overall_score`, map creator info from profiles lookup by user_id
- Sort the array by `overall_score` descending (nulls last)
- Store in `analyses` state
- Set `initialLoad = false` after fetch

**Pagination (client-side):**
- `const [visibleCount, setVisibleCount] = useState(PAGE_SIZE)` -- how many to show
- Render `analyses.slice(0, visibleCount)`
- "Load More" button visible when `visibleCount < analyses.length`
- Button onClick: `setVisibleCount(prev => prev + PAGE_SIZE)`

**Layout:**
- Outer: `<div className="max-w-6xl mx-auto px-4 py-12 space-y-8">`
- Header section:
  - `<h1 className="text-3xl font-headline font-bold text-on-surface">Discover</h1>`
  - `<p className="text-on-surface-variant text-sm">Browse public neural analyses ranked by brain activation score</p>`
- Grid: `<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">`
  - Map over `analyses.slice(0, visibleCount)` rendering `<DiscoverCard key={a.id} analysis={a} />`
- Loading state: while `initialLoad` is true, show 6 skeleton cards (simple `<div className="bg-surface-container rounded-xl animate-pulse"><div className="aspect-video bg-surface-container-highest rounded-t-xl" /><div className="p-4 space-y-2"><div className="h-4 bg-surface-container-highest rounded w-3/4" /><div className="h-3 bg-surface-container-highest rounded w-1/2" /></div></div>`)
- Empty state: when `!initialLoad && analyses.length === 0`, show `<div className="col-span-full py-20 text-center text-on-surface-variant">No public analyses yet. Be the first to share!</div>`
- Load More button (below grid): `<div className="text-center"><button onClick={() => setVisibleCount(v => v + PAGE_SIZE)} className="px-6 py-3 bg-surface-container-high text-on-surface font-headline text-sm uppercase tracking-widest rounded-lg hover:bg-surface-container-highest transition-colors">Load More</button></div>` -- only rendered when `visibleCount < analyses.length`

**SEO note:** Since this is a client component, add a `<title>` via next/head or use the `metadata` export trick. Actually, for a client component in Next.js App Router, export metadata from a separate `layout.tsx` is preferred.
