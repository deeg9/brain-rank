Read the key interactions guide HTML file and all 5 canonical screen spec Interactions sections. Extract every interaction pattern, de-duplicate shared patterns, and organize by pattern type.

Create ui-specs/interactions.md with the following structure:

**Header:** Title, purpose statement, note that interactions reference components from components.md.

**Group interactions by pattern type (not by screen):**

**1. Timeline Interactions**
Patterns from Results Overview and Results Detail specs + key interactions guide:
- Timeline scrubbing (hover): Trigger = mouse hover on timeline segment. Behavior = tooltip appears showing time range, activation score, and region breakdown (4 regions). Tooltip format defined. Edge cases: hover near edge of segment boundary, hover on gap between segments.
- Timeline click (seek): Trigger = click on timeline position. Behavior = video player seeks to that timestamp, detail panel updates. Edge cases: click on a position with no segment data.
- Playhead drag: Trigger = mousedown on playhead + drag. Behavior = scrubs video position in real-time, updates current time display. Note from key interactions guide: "Drag playhead - Scrub both videos simultaneously" (adapted to single video for v1). Edge cases: drag beyond timeline bounds.
- Region track filtering: Trigger = click on a region track label (Detail view). Behavior = filters main timeline to show only that region's data. From key interactions guide: "Click region track - Filters main timeline to show only that region."
- Track collapse/expand: Trigger = click track section header toggle. Behavior = shows/hides brain region tracks section. Results Detail only.
- Hook zone marker: Static visual element at ~5s mark. Not interactive but important for context.

**2. Video Playback Interactions**
Patterns from key interactions guide + Results specs:
- Play/pause: Trigger = click play button on video player or press Spacebar. Behavior = toggles video playback. From key interactions guide: "Play/pause - Both videos sync" (single video for v1).
- Keyboard seek: Trigger = press left/right arrow keys. Behavior = seek +/- 2 seconds. From key interactions guide: "Arrow keys - Seek +/- 2 seconds."
- Video-timeline sync: When video plays, playhead on timeline advances in sync. When timeline is clicked, video seeks. Bidirectional sync.

**3. Drag-and-Drop Interactions**
Patterns from Upload spec:
- File drop: Trigger = drag file over drop zone. Behavior = border transitions to primary/50, background brightens. On drop: validate (format, size), begin upload. Edge cases: wrong format, too large, multiple files (reject all but first).
- File browse fallback: Trigger = click "Browse Files" button. Behavior = native file picker opens filtered to .mp4, .mov, .mkv. Same validation flow as drag-and-drop.

**4. Navigation Interactions**
Patterns from all screens:
- Sidebar nav: Trigger = click nav item. Behavior = navigate to target screen. Active item has left border accent + surface-container background.
- Back navigation: Trigger = click back arrow in top bar. Behavior = navigate to previous screen (Dashboard from Results, Overview from Detail).
- "New Analysis" CTA: Trigger = click button in sidebar or dashboard header. Behavior = navigate to Upload screen.
- Summary card click: Trigger = click a metric card on Results Overview. Behavior = scrolls to relevant timeline section (e.g., Peak Moment card jumps to peak segment). From key interactions guide: "Click summary card - Jumps to relevant moment."
- Moments tag click: Trigger = click a tagged moment pill. Behavior = jump to that labeled moment on timeline. From key interactions guide: "Click 'Moments' tag - Jump to that labeled moment."

**5. Data Export Interactions**
Patterns from Results Detail spec:
- JSON export: Trigger = click JSON button. Behavior = client-side serialization of OutputSchema, triggers browser download as .json file. Brief spinner during generation.
- CSV export: Trigger = click CSV button. Behavior = flatten segment data to rows, trigger download as .csv. Brief spinner.
- Share link (aspirational): Noted as future pattern.

**6. Search and Filter Interactions**
Patterns from Dashboard spec:
- Search analyses: Trigger = type in search input. Behavior = filter job history grid by filename substring match. Edge cases: no matches (show "No results" state), empty search (show all).
- Sort job history: Trigger = click sort control. Behavior = re-order grid by date/score/status.
- Pagination: Trigger = scroll to bottom or click "Load More." Behavior = load next batch of job cards.

**7. Polling and Auto-Update Interactions**
Patterns from Processing spec:
- Job status polling: Trigger = automatic on page load with job_id. Behavior = GET /status/{job_id} every 3-5 seconds. State transitions: IN_QUEUE -> IN_PROGRESS -> COMPLETED | FAILED.
- Auto-redirect on completion: When polling returns COMPLETED, brief animation (1-2s), then redirect to Results Overview.
- Resume polling: If user navigates away and returns, polling resumes from current state. If job already completed, immediate redirect.
- Client-side timeout: After 30 min with no completion, show timeout warning.

**8. Hover and Feedback Interactions**
Patterns across multiple screens:
- Button hover: Scale-on-hover for neural-gradient CTAs, border brightening for secondary buttons.
- Card hover: Job cards on Dashboard lift border to primary/30 on hover.
- Nav item hover: Inactive items brighten on hover.
- Tooltip pattern: Used on timeline segments (score + regions) and metric cards (additional context).

**For each interaction pattern, document:**
- Pattern name
- Trigger (user action)
- Behavior (what happens)
- Components involved (reference components.md names)
- Screens where it appears
- Edge cases / error states
- v1 implementation notes (what is real vs placeholder in v1)

**End with a Screen-to-Interaction Matrix:** Table mapping each interaction to which screens it appears on.
