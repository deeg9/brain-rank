Read DESIGN.md thoroughly and extract every design token. Then cross-reference against the 5 canonical screen specs to validate which tokens are actually used and identify any tokens used in specs but not defined in DESIGN.md.

Create ui-specs/design-tokens.md with the following structure:

**1. Color Tokens**

Surface hierarchy (from DESIGN.md Section 2):
- surface (#0e0e10) -- "The canvas"
- surface_container_low (#131315) -- navigation, sidebars
- surface_container (#19191c) -- primary editor/timeline area
- surface_container_high (#1f1f22) -- floating/actionable elements
- surface_container_highest (#262528) -- elevated elements
- surface_container_lowest (#000000) -- recessed elements
- surface_bright -- glassmorphism (60% opacity + 20px backdrop blur)

Accent colors:
- primary (#ba9eff) -- Electric Purple, main brand accent
- primary_dim (#8455ef) -- Gradient endpoint for neural-gradient
- primary_container -- Neural chip backgrounds
- on_primary_container -- Neural chip text
- secondary (#5af8fb) -- Cyan/Teal, AI processing
- secondary_fixed (#5af8fb) -- Standard AI processing
- tertiary (#9bffce) -- Emerald green, high engagement/success
- error (#ff6e84) -- Crimson, low engagement/errors

Text colors:
- on_surface (#f6f3f5) -- Primary text (NOT 100% white)
- on_surface_variant (#acaaad) -- Secondary/muted text
- on_background -- Shadow color at 4% opacity

Outline:
- outline_variant -- Ghost borders at 15% opacity

Include the "No-Line Rule" (1px solid borders prohibited), "Glass & Gradient Rule" (glassmorphism specs), and "Ghost Border" rule from DESIGN.md.

**2. Typography Tokens**

Font families:
- Display/Headlines: Space Grotesk -- "Technical Editorial" face
- Body/Labels: Inter -- maximum legibility at high density
- Monospace: (used in Inference Log Panel) -- identify from specs

Type scale (from DESIGN.md Section 3):
- display-lg -- hero metrics
- headline-lg -- major titles
- headline-sm -- section headers
- body-md -- descriptions
- body-sm -- compact information
- label-sm -- timestamps, metadata

Include the "Leaps of Scale" rule (never use sizes only 2px apart).

**3. Spacing Tokens**

Extract from DESIGN.md and specs:
- 16px and 24px vertical padding (cards/lists from DESIGN.md Section 5)
- Sidebar width: 256px (w-64) -- from all specs
- Content max-width: 7xl (Upload), 4xl (Processing)
- Grid: 12-column layout (Results)
- Border radius scale: sm (2px), md (6px), lg (8px), xl (12px) -- from DESIGN.md Section 6

**4. Elevation Tokens**

From DESIGN.md Section 4:
- Ambient shadow: 32px blur, 0px offset, on_background at 4% opacity
- Layering principle: lowest on low = recessed, high on surface = lifted
- Ghost border: outline_variant at 15% opacity

**5. Semantic Mappings**

Map design tokens to their semantic use in the product:
- Timeline high engagement: tertiary (#9bffce) when activation_score > 0.7
- Timeline stable engagement: secondary (#5af8fb) when activation_score 0.4-0.7
- Timeline drop-off: error (#ff6e84) when activation_score < 0.4
- Region track colors: Attention = primary, Reward = tertiary, Emotional = secondary, Social = on-surface-variant muted
- Neural-gradient: linear-gradient from primary to primary_dim (progress bars, CTA buttons)
- Active nav item: left border accent primary, surface-container background

**6. Validation Notes**

Document any discrepancies between DESIGN.md and actual spec usage (tokens mentioned in DESIGN.md but not used in any spec, or colors used in specs without a DESIGN.md token).
