       - rank: number (1 = highest peak)
       - dominantRegion: string (human-readable name of highest region score, e.g. "Attention", "Reward")

       - Algorithm:

         f. For dominantRegion: find the key in segment.regions with the highest value, map to human-readable name using a const map (attention -> "Attention", emotional_processing -> "Emotional Processing", etc.)
