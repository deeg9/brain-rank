         ```sql
         create or replace function public.increment_view_count(p_job_id uuid)
         returns void as $$
         begin
           update public.jobs
           set view_count = view_count + 1
           where id = p_job_id and is_public = true;
         end;
         $$ language plpgsql security definer;
         ```

| T-51-01 | Tampering | increment_view_count RPC | accept | View count inflation via repeated calls is low-value; no PII. Rate limiting deferred -- acceptable for validation phase. RPC uses `security definer` + checks `is_public = true` so private jobs cannot be probed. |
| T-51-02 | Elevation of Privilege | bookmarks RLS | mitigate | RLS policies enforce `auth.uid() = user_id` on all operations. Users cannot read/write other users' bookmarks. |
| T-51-03 | Information Disclosure | GET /api/bookmarks/[id] | mitigate | Returns `{ bookmarked: false }` for unauthenticated users -- does not leak whether a job exists or is public. |
| T-51-04 | Spoofing | bookmark API auth | mitigate | All bookmark mutations require valid Supabase session. 401 returned if no session. |
