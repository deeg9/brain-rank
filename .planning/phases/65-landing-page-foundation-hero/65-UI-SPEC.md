# Phase 65 — UI Design Contract

> Visual and interaction contract for Landing Page Foundation & Hero. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | custom (existing Button, Card, etc. in `web/src/components/ui/`) |
| Icon library | Material Symbols Outlined (already loaded via Google Fonts CDN) |
| Font | Space Grotesk (headlines) + Inter (body) — already loaded in `layout.tsx` |

**Landing page scoping:** All landing page styles are scoped via a `data-landing` attribute on the page wrapper element. This remaps design tokens to grayscale values without affecting the app's purple/cyan theme.

## Typography

| Role | Font | Size | Weight | Line Height | Usage |
|------|------|------|--------|-------------|-------|
| Display | Space Grotesk | 72px (lg), 48px (md), 36px (sm) | 700 (bold) | 1.1 | Hero headline "See What Brains See" |
| Body | Inter | 20px (lg), 18px (md), 16px (sm) | 400 (regular) | 1.5 | Value proposition subhead |
| Label | Inter | 14px | 400 (regular) | 1.4 | Header login link, footer text |
| Mono | monospace (system) | 12px | 400 | 1.2 | Footer version string, feature pill text (uppercase, tracking-wider) |

Responsive breakpoints for typography:
- `sm` = below 768px (mobile)
- `md` = 768px-1023px (tablet)
- `lg` = 1024px+ (desktop)

Headline tracking: `tracking-tight` (-0.025em) on display text for brutalist density.

## Color

Landing page operates on a fully isolated grayscale palette via `[data-landing]` token overrides. The app theme is untouched.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#000000` | Page background — pure black for maximum brutalist contrast |
| Secondary (30%) | `#111111` / `#1a1a1a` | Feature pills background, subtle surface differentiation |
| Text primary | `#ffffff` | Headline, CTA button text, wordmark |
| Text secondary | `#999999` | Value proposition subhead, login link, footer |
| Accent (10%) | `#ffffff` | CTA button border, brain glow/bloom, hover states |
| Destructive | not applicable | No destructive actions in this phase |

Accent reserved for: CTA button border and hover-fill, brain mesh shimmer/bloom glow effect, wordmark separator pipe character.

**CTA button states:**
| State | Style |
|-------|-------|
| Default | White 1px border, transparent fill, white text |
| Hover | White fill, black text (invert) |
| Active | White fill at 90% opacity, black text, `scale(0.98)` |
| Focus | White 2px outline with 2px offset for accessibility |

**Brain glow:** Monochrome white shimmer on mesh vertices, soft white bloom via `@react-three/postprocessing` `Bloom` pass. No colored lights.

**`[data-landing]` token overrides** (added to `globals.css`):

```css
[data-landing] {
  --color-surface: #000000;
  --color-background: #000000;
  --color-on-surface: #ffffff;
  --color-on-background: #ffffff;
  --color-on-surface-variant: #999999;
  --color-surface-container: #111111;
  --color-outline-variant: rgba(255, 255, 255, 0.1);
}
```

## Component Inventory

Components required for Phase 65:

| Component | Source | Notes |
|-----------|--------|-------|
| `LandingPage` | New | Root page component at `app/page.tsx`, wraps everything in `data-landing` div |
| `LandingHeader` | New | Minimal header: "BRAIN\|RANK" wordmark (left) + "Login" link (right) |
| `BrainHero` | New | Decorative 3D brain wrapper — renders brain mesh with auto-rotation, shimmer, bloom. No segment data, no tooltips, no OrbitControls for user. |
| `HeroContent` | Evolve from `HeroOdyssey` | Headline, subhead, CTA button, feature pills — layered on top of BrainHero with z-index |
| `Button` | Existing (`web/src/components/ui/Button.tsx`) | Add a new `"landing"` variant: ghost/outline style with white border, invert on hover |

**BrainHero Three.js specifics:**
- Camera: perspective, fov 45, distance 3.5 units from origin
- Auto-rotation: `autoRotate` at speed 0.3 (slow, ambient)
- No OrbitControls (user cannot drag — purely decorative)
- Bloom: intensity 1.5, luminance threshold 0.6, radius 0.8
- Shimmer: vertex displacement at 0.5Hz, amplitude 0.002 units
- Brain mesh material: `MeshStandardMaterial` with emissive white at 0.15 intensity, base color `#333333`
- Ambient light: white at 0.3 intensity
- Point light: white at 0.8 intensity, position [2, 3, 4]

## Accessibility

- CTA button must have visible focus indicator (white 2px outline, 2px offset)
- Login link must have visible focus indicator
- Color contrast: white `#ffffff` on black `#000000` = 21:1 ratio (WCAG AAA)
- Color contrast: gray `#999999` on black `#000000` = 5.1:1 ratio (WCAG AA for large text, subhead qualifies at 18px+)
- `aria-hidden="true"` on 3D brain canvas (decorative, not interactive)
- `prefers-reduced-motion`: disable Framer Motion animations and brain auto-rotation (set elements to final state immediately)
