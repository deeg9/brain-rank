```typescript
interface AdjacentSegmentResult {
  currentVertexData: string;       // base64 vertex_data for current segment
  nextVertexData: string | null;   // base64 vertex_data for next segment (null if last or same segment)
  blendFactor: number;             // 0.0 = fully current, 1.0 = fully next
}
```

Logic:
- Find the segment containing `time` (same as existing getVertexDataAtTime logic)
- Find the NEXT segment in the array (segments are ordered by start time)
- Compute blend factor: when time is within the last 300ms of the current segment (i.e., `time >= seg.end - 0.3`), compute `blendFactor = (time - (seg.end - 0.3)) / 0.3` clamped to [0, 1]
- Outside that 300ms window, blendFactor = 0 (no blending)
- If nextVertexData is null (last segment or no vertex_data on next), blendFactor stays 0

2. In BrainViewer.tsx, replace the single `getVertexDataAtTime` call with `getAdjacentSegments`:
- Decode BOTH vertex data strings into Float32Arrays via `decodeVertexData`
- Cache decoded arrays with useMemo keyed on the base64 strings
- Pass `vertexDataA`, `vertexDataB`, and `blendFactor` to BrainGlowMesh instead of single `vertexData`

Keep the existing ~4Hz React state update rate -- the blend factor changes will be handled in the render loop (Task 2).

```typescript
function lerpVertexData(
  a: Float32Array,
  b: Float32Array,
  t: number,
  out: Float32Array
): void {
  for (let i = 0; i < a.length; i++) {
    out[i] = a[i] + (b[i] - a[i]) * t;
  }
}
```
