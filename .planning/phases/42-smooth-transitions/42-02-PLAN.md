1. Add state and refs for idle detection:

```typescript
const [isIdle, setIsIdle] = useState(false);
const idleTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
const IDLE_TIMEOUT_MS = 3000;
const AUTO_ROTATE_SPEED = 0.5; // slow rotation (drei default is 2.0)
```

2. Create a `resetIdleTimer` callback:
```typescript
const resetIdleTimer = useCallback(() => {
  setIsIdle(false);
  if (idleTimerRef.current) clearTimeout(idleTimerRef.current);
  idleTimerRef.current = setTimeout(() => setIsIdle(true), IDLE_TIMEOUT_MS);
}, []);
```

3. Wire OrbitControls events to reset idle timer. OrbitControls from drei exposes `onStart` and `onEnd` events. Use `onStart` to immediately pause auto-rotate (call resetIdleTimer which sets isIdle=false). This provides instant pause on grab.

4. Initialize the idle timer on mount so auto-rotate kicks in after the initial 3s:
```typescript
useEffect(() => {
  const timer = setTimeout(() => setIsIdle(true), IDLE_TIMEOUT_MS);
  return () => clearTimeout(timer);
}, []);
```

5. Clean up idleTimerRef on unmount:
```typescript
useEffect(() => {
  return () => {
    if (idleTimerRef.current) clearTimeout(idleTimerRef.current);
  };
}, []);
```

6. Update OrbitControls props:
```tsx
<OrbitControls
  ref={controlsRef}
  enablePan={false}
  minDistance={100}
  maxDistance={400}
  autoRotate={isIdle}
  autoRotateSpeed={AUTO_ROTATE_SPEED}
  enableDamping
  dampingFactor={0.08}
  rotateSpeed={0.8}
  onStart={resetIdleTimer}
/>
```

The `onStart` event fires when the user begins interacting (mousedown/touchstart on controls). This immediately sets `isIdle=false` (stopping autoRotate) and starts the 3s timer. When the timer expires without new interactions, `isIdle` becomes true and autoRotate resumes.

Note: Do NOT use `onChange` -- it fires on every frame during auto-rotate itself, creating a feedback loop that prevents auto-rotation from ever engaging.
