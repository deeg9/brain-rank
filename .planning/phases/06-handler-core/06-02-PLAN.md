Create src/video_fetcher.py implementing secure video download:

**Constants:**
- `MAX_VIDEO_SIZE = 500 * 1024 * 1024` (500MB)
- `DOWNLOAD_TIMEOUT = 120` (seconds)
- `CHUNK_SIZE = 8192`

**SSRF prevention -- `_validate_url(url: str) -> str`:**
- Parse URL with `urllib.parse.urlparse`
- Reject non-http/https schemes (raise ValueError)
- Resolve hostname to IP using `socket.getaddrinfo`
- Check resolved IP against private ranges using `ipaddress.ip_address(addr).is_private` or `.is_loopback` or `.is_reserved` or `.is_link_local`
- If any resolved address is private/loopback/reserved/link_local, raise ValueError("URL resolves to a private IP address")
- Return the original URL if valid

**Download -- `download_video(url: str, job_id: str) -> Path`:**
- Call `_validate_url(url)` first
- Create output path: `/tmp/video_{job_id}.mp4`
- Use `requests.get(url, stream=True, timeout=DOWNLOAD_TIMEOUT, allow_redirects=True)`
- Call `response.raise_for_status()`
- Check Content-Length header if present: reject if > MAX_VIDEO_SIZE
- Stream download in CHUNK_SIZE chunks, tracking total bytes written
- If total bytes exceed MAX_VIDEO_SIZE during download, delete partial file and raise ValueError
- Return Path to downloaded file
- Use `logging.getLogger(__name__)` for INFO-level logs: "Downloading video for job {job_id}...", "Video downloaded: {size_mb:.1f}MB"

**Important:** Do NOT catch requests exceptions here -- let them propagate to handler.py which wraps them in ErrorResponse.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04 | Spoofing | video_fetcher._validate_url | mitigate | Resolve hostname and check IP against private/loopback/reserved/link-local ranges before making request (SSRF prevention) |
| T-06-05 | Denial of Service | video_fetcher.download_video | mitigate | Enforce 500MB max file size via Content-Length header check AND streaming byte count. 120s download timeout. |
| T-06-06 | Tampering | video_fetcher.download_video | accept | Downloaded file could be non-video (e.g., malicious binary). Acceptable: TRIBE v2 will fail on invalid video, and file is cleaned up in finally block. No execution of downloaded content. |
| T-06-07 | Information Disclosure | handler.py error responses | mitigate | ErrorResponse returns error message and type only. No stack traces, no file paths, no internal state in error responses. |
| T-06-08 | Denial of Service | handler.py temp files | mitigate | finally block ensures video_path.unlink() runs even on exceptions. Prevents /tmp disk exhaustion across jobs. |
</threat_model>
