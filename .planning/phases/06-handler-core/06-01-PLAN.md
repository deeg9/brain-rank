**get_model() function:**
- Uses a module-level `_model: TribeModel | None = None` variable
- On first call: loads `TribeModel.from_pretrained("facebook/tribev2")` (no cache_folder arg -- use default HuggingFace cache which respects HF_HOME/TRANSFORMERS_CACHE env vars and works with RunPod network volumes)
- Logs model loading start and completion with timing (`logging.getLogger(__name__)`)
- Returns the cached instance on subsequent calls
- Does NOT catch exceptions -- model load failure should crash the container at startup (fail-fast, don't serve broken requests)

- Import `TribeModel` inside the function body, not at module top level. This avoids import errors when running schema tests on machines without GPU/tribev2 installed.
- Use `time.perf_counter()` for timing the load
- Log at INFO level: "Loading TribeModel..." and "TribeModel loaded in {seconds:.1f}s"
