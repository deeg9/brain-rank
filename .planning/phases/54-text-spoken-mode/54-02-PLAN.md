```python
def run_text_inference(model, text_path: str, job_id: str) -> tuple[np.ndarray, list, dict]:
    """Run TRIBE v2 inference on a text file via native TTS pipeline.

    TRIBE v2 internally converts text to speech (gTTS), extracts audio features
    (Wav2Vec-BERT), and transcribes for text features (LLaMA 3.2).

    Parameters
    ----------
    model : TribeModel
        Loaded TRIBE v2 model instance.
    text_path : str
        Path to a .txt file containing the text content.
    job_id : str
        Unique job identifier for log correlation.

    Returns
    -------
    tuple[np.ndarray, list, dict]
        - predictions: numpy ndarray of shape (n_segments, 20484)
        - segments: list of Segment namedtuples from TRIBE v2
        - timing: dict with "events_extract_s" and "inference_s" as floats
    """
    # Step 1: Extract events from text (TRIBE v2 handles TTS internally)
    logger.info("Job %s: extracting events from text %s", job_id, text_path)
    t0 = time.perf_counter()
    df = model.get_events_dataframe(text_path=text_path)
    t1 = time.perf_counter() - t0
    logger.info(
        "Job %s: text events extracted — %d events in %.1fs",
        job_id,
        df.shape[0],
        t1,
    )

    # Step 2: Run inference
    logger.info("Job %s: running inference on text...", job_id)
    t0 = time.perf_counter()
    preds, segments = model.predict(events=df)
    t2 = time.perf_counter() - t0

    # Step 3: Convert torch tensor to numpy if needed
    if hasattr(preds, "detach"):
        preds = preds.detach().cpu().numpy()

    logger.info(
        "Job %s: text inference complete — %d segments, shape %s in %.1fs",
        job_id,
        len(segments),
        preds.shape,
        t2,
    )

    return (
        preds,
        segments,
        {
            "events_extract_s": round(t1, 2),
            "inference_s": round(t2, 2),
        },
    )
```

Key differences from run_inference:

- Calls `model.get_events_dataframe(text_path=text_path)` instead of `video_path=video_path`
- Log messages say "text" instead of "video" for clarity
- Same return signature — postprocessor does not need changes
