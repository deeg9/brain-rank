**Props interface:**
```typescript
interface FileItem {
  id: string;        // crypto.randomUUID()
  file: File;
  thumbnail?: string; // data URL from VideoThumbnail
  progress: number;   // 0-100, controlled by parent
  status: 'pending' | 'uploading' | 'complete' | 'error';
  error?: string;
}

interface AnimatedFileUploadProps {
  files: FileItem[];
  onFilesAdd: (files: File[]) => void;
  onFileRemove: (id: string) => void;
  disabled?: boolean;
  maxFiles?: number;      // default 5
  maxSizeBytes?: number;  // default 2GB
  acceptedTypes?: string[]; // default ['video/mp4', 'video/webm', 'video/quicktime']
}
```

Export the `FileItem` type for use in the parent page.

**Drop zone (when files list is empty or as persistent add-more area):**
- Use native drag events (onDragEnter, onDragLeave, onDragOver, onDrop) -- no react-dropzone dependency needed.
- Wrap the drop zone in `motion.div` from framer-motion.
- Default state: `glass-surface rounded-xl ghost-border` background, dashed border with `border-outline-variant/30`, height `h-64`.
- Contains centered cloud_upload Material Symbol icon (text-3xl), headline text "Drop videos here or click to browse", subtitle with accepted formats, and a "Browse Files" Button (variant="secondary").
- Hidden file input with `accept="video/*"` and `multiple` attribute, triggered by Browse button click.

**Drag-active state animation (Framer Motion):**
- On dragEnter: animate to `{ scale: 1.02, borderColor: 'rgba(186, 158, 255, 0.6)' }` with spring transition (stiffness: 300, damping: 25).
- Add a glow effect: an absolutely positioned inner div with `bg-primary-dim/10` that animates opacity from 0 to 1 on drag active.
- Border transitions from dashed `border-outline-variant/30` to solid `border-primary-dim/50`.
- On dragLeave/drop: animate back to default with same spring.

**File list (below drop zone):**
- Wrap file list in `<AnimatePresence mode="popLayout">` from framer-motion.
- Each file row is a `motion.div` with:
  - `initial={{ opacity: 0, y: 20, scale: 0.95 }}`
  - `animate={{ opacity: 1, y: 0, scale: 1 }}`
  - `exit={{ opacity: 0, x: -20, scale: 0.95 }}`
  - `transition={{ type: "spring", stiffness: 300, damping: 30 }}`
  - `layout` prop for smooth reordering.

**Each file row contains:**
- Left side: VideoThumbnail component (48x48 rounded-lg) or a movie icon placeholder while thumbnail loads.
- Middle: file name (font-headline font-semibold, truncate), file size in human format (text-on-surface-variant text-sm).
- Progress bar: a `motion.div` with `style={{ width: `${progress}%` }}` animated via `animate={{ width: `${progress}%` }}` with spring transition. Bar has `h-1.5 rounded-full` with gradient `bg-gradient-to-r from-primary-dim to-secondary-fixed` (purple #ba9eff to cyan #5af8fb). Track is `bg-surface-container-highest rounded-full h-1.5`.
- Right side: status indicator -- checkmark icon for complete, spinner for uploading, X button (ghost variant) to remove (calls onFileRemove).
- Row background: `bg-surface-container-high rounded-xl p-4 ghost-border`.

**Validation on add:**
- Check file type against acceptedTypes. Show inline error via a brief shake animation on the drop zone if invalid.
- Check file size against maxSizeBytes.
- Check total file count against maxFiles.
- For validation errors: do NOT add the file, flash a red error message below the drop zone with `<AnimatePresence>` fade in/out.

**File input handling:**
- Support both single and multiple file selection.
- On file input change or drop, call `onFilesAdd` with the array of valid File objects.

  <name>Task 2: Create VideoThumbnail component with HTML5 canvas capture</name>
  <files>web/src/components/upload/VideoThumbnail.tsx</files>
  <action>
Create a "use client" component at web/src/components/upload/VideoThumbnail.tsx.

**Props:**
```typescript
interface VideoThumbnailProps {
  file: File;
  onThumbnailGenerated: (dataUrl: string) => void;
  className?: string;
}
```

**Implementation:**
1. Use `useEffect` on mount: create a hidden HTML5 `<video>` element, set `src` to `URL.createObjectURL(file)`.
2. On the video's `loadeddata` event, seek to `currentTime = 1` (1 second in -- avoids black frames at start).
3. On `seeked` event, draw the video frame onto a hidden `<canvas>` element scaled to 96x96, then call `canvas.toDataURL('image/jpeg', 0.7)`.
4. Pass the data URL to `onThumbnailGenerated` callback.
5. Revoke the object URL in cleanup to prevent memory leaks.
6. Store the thumbnail data URL in local state.

**Render:**
- If thumbnail exists: `<img>` with the data URL, `rounded-lg object-cover` and the size from className (default w-12 h-12).
- If loading: a pulsing placeholder div (`animate-pulse bg-surface-container-highest rounded-lg`) at same size.

**Error handling:**
- If video cannot load (corrupt file, unsupported codec): show a fallback movie icon (Material Symbol "movie") in a rounded-lg container with `bg-surface-container-highest`.
- Set a 5-second timeout -- if thumbnail generation hasn't completed, fall back to the icon.
