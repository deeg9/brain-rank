- Download spaCy model: `python -m spacy download en_core_web_sm`

Create `scripts/test_inference.py` — the main Phase 1 validation script. This script runs TRIBE v2 inference on a test video and logs the raw output format. Must:

1. **CUDA gate**: Check `torch.cuda.is_available()`. If False, print error and exit(1). Print GPU name and VRAM.

2. **Test video resolution**: Accept video path as CLI argument (`sys.argv[1]`). If no argument, check `test_videos/` directory for any .mp4 file. If no video found, print instructions for downloading the Sintel trailer and exit(1):
   ```
   No test video found. Download a 60-second test video:
     wget -O test_videos/test_video.mp4 "https://download.blender.org/demo/movies/Sintel.2010.720p.mkv"
   Or provide path as argument:
     python scripts/test_inference.py /path/to/video.mp4
   ```

3. **Model loading**: Load model with `TribeModel.from_pretrained("facebook/tribev2", cache_folder="./cache")`. Time the loading with `time.time()`. Print duration.

4. **Events extraction**: Call `model.get_events_dataframe(video_path=VIDEO_PATH)`. Time it. Print:
   - Events dataframe shape
   - Column names (df.columns.tolist())
   - Event types (df['type'].unique().tolist() if 'type' column exists)
   - First 3 rows (df.head(3).to_string())

5. **Inference**: Call `model.predict(events=df)`. Time it. Unpack as `preds, segments = model.predict(events=df)`.

6. **Output logging** (critical for Phase 2):
   - `preds` type, shape, dtype, min, max, mean, std
   - Number of segments, type of segments
   - First segment content (if list/dict, print first element)
   - Whether preds is a numpy array or torch tensor

7. **GPU memory**: Print `torch.cuda.max_memory_allocated()` and `torch.cuda.max_memory_reserved()` in GB.

8. **Timing summary**: Print total time breakdown: model_load_s, events_extract_s, inference_s, total_s.

9. **JSON output**: Also write a machine-readable summary to `docs/inference_output.json` with keys: gpu_name, gpu_vram_gb, predictions_shape, predictions_dtype, predictions_min, predictions_max, predictions_mean, n_segments, model_load_s, events_extract_s, inference_s, total_s, max_vram_allocated_gb, video_path, timestamp.

All print statements should use a clear `=== SECTION ===` format for easy reading. The script must be self-contained (no project imports) and work on any Linux machine with TRIBE v2 installed.
