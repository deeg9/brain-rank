After the user provides inference results from Task 1, create `docs/model_output_format.md` documenting the raw TRIBE v2 output format. Use actual measured values from `docs/inference_output.json` (not assumptions). The document must include:

**Section 1: Output Shape**
- predictions shape: (n_timesteps, 20484) — use actual n_timesteps from the run
- Temporal resolution: 1 prediction per second of stimulus (verify from actual data)
- Spatial resolution: 20,484 cortical vertices (fsaverage5 mesh, 10,242 per hemisphere)
- Data type: actual dtype from inference_output.json

**Section 2: Value Range**
- min, max, mean, std from actual inference run
- Whether values are normalized or raw fMRI-scale activations

**Section 3: Timing**
- Model load time (seconds)
- Events extraction time (seconds)
- Inference time (seconds)
- Total time (seconds)
- GPU used and VRAM consumed

**Section 4: Events DataFrame**
- Column names from actual run
- Event types found
- Number of events for the test video

**Section 5: Segments**
- Type and structure of segments output
- First segment content

**Section 6: Hemodynamic Delay Note**
- Prediction at time T corresponds to stimulus at T-5 seconds (from RESEARCH.md)
- This must be accounted for in Phase 2 temporal alignment

**Section 7: Implications for Phase 2**
- What mapping is needed (vertices to brain regions)
- What the raw output is NOT (not engagement scores, not activation scores — raw predicted fMRI)
- References to fsaverage5 atlas for vertex-to-region mapping
