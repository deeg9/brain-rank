Create scripts/validate_model.py that:

1. Takes two video paths as CLI arguments: `python scripts/validate_model.py /path/to/high.mp4 /path/to/low.mp4`
2. For EACH video:
   a. Loads TRIBE v2 model (load once, reuse for both): `TribeModel.from_pretrained("facebook/tribev2", cache_folder="./cache")`
   b. Runs `model.get_events_dataframe(video_path=path)` then `model.predict(events=df)`
   c. Records timing for each stage (model_load_s, events_extract_s, inference_s, total_s)
   d. Records GPU stats: `torch.cuda.max_memory_allocated()`, `torch.cuda.get_device_name(0)`
   e. Saves raw predictions as .npy to `data/predictions_high.npy` and `data/predictions_low.npy` (so we have the raw data for future analysis)
3. After both videos are processed:
   a. Loads pre-computed masks from `data/region_masks.npz` using the same `load_masks()` pattern from validate_mapping.py
   b. For each video's predictions, applies `align_to_stimulus()` for hemodynamic correction
   c. Computes `compute_region_scores()` for each aligned prediction set
   d. For each of the 4 regions (attention, reward, emotional_processing, social_cognition), computes:
      - Mean activation for high-engagement video
      - Mean activation for low-engagement video
      - Difference (high - low)
      - Cohen's d effect size: `(mean_high - mean_low) / pooled_std` where `pooled_std = sqrt((std_high**2 + std_low**2) / 2)`
      - A simple interpretation: |d| > 0.2 = small, > 0.5 = medium, > 0.8 = large (Cohen's conventions)
   e. Prints a formatted comparison table to stdout
   f. Writes a JSON file to `data/validation_comparison.json` containing:
      ```json
      {
        "high_engagement": {"video": "...", "n_segments": N, "n_aligned_segments": M, "timing": {...}, "region_means": {...}},
        "low_engagement": {"video": "...", "n_segments": N, "n_aligned_segments": M, "timing": {...}, "region_means": {...}},
        "comparison": {
          "per_region": {
            "attention": {"high_mean": X, "low_mean": Y, "diff": Z, "cohens_d": D, "interpretation": "..."},
            ...
          },
          "overall_differentiation": true/false,
          "differentiation_summary": "..."
        },
        "gpu": {"name": "...", "vram_peak_gb": ...},
        "timestamp": "..."
      }
      ```
   g. The `overall_differentiation` flag is true if at least 2 of the 4 regions show |Cohen's d| > 0.2 (small effect). This is a conservative threshold -- we just need evidence the model sees SOMETHING different.

The script must import from the project: `from src.region_mapping.scoring import compute_region_scores`, `from src.region_mapping.temporal import align_to_stimulus`, etc. Use the same `sys.path.insert(0, PROJECT_ROOT)` pattern from validate_mapping.py.
