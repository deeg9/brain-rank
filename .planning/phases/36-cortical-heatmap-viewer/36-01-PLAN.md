  <name>Task 2: Create BrainHeatmapMesh component with per-vertex coloring</name>
  <files>web/src/components/results/BrainHeatmapMesh.tsx</files>
  <action>
Create `web/src/components/results/BrainHeatmapMesh.tsx`:

Props interface:
```typescript
interface BrainHeatmapMeshProps {
  vertexData: Float32Array;  // 20,484 normalized values from decodeVertexData
  colormap: ColormapName;
}
```

Implementation:
1. Load the unified GLB: `const { nodes } = useGLTF('/models/brain-fsaverage5-unified.glb')` -- cast nodes type as `Record<string, THREE.Mesh>`.
2. Get geometry from `nodes.brain.geometry`.
3. Use `useMemo` to clone the geometry once (so we don't mutate the cached original). Call `geometry.clone()` and store it. The clone only runs when the geometry reference changes (effectively once).
4. Pre-allocate a color buffer with `useMemo`: `new Float32Array(VERTEX_COUNT * 3)` (from vertex-codec.ts constant).
5. On the cloned geometry, set `geometry.setAttribute('color', new THREE.BufferAttribute(colorBuffer, 3))`.
6. Use `useFrame` to update colors each frame:
   - Call `applyColormap(vertexData, colormap, colorBuffer)` to write RGB values into the pre-allocated buffer.
   - Set `geometry.attributes.color.needsUpdate = true` to flag GPU upload.
   - NOTE: applyColormap runs on every frame, but since it mutates in-place with no allocations, this is efficient. The d3 interpolator calls are the cost -- for 20,484 vertices this is acceptable (~1ms).
7. Actually, to avoid running d3 interpolators every frame (60fps * 20k vertices = expensive), optimize: use a `useRef` to track whether vertexData or colormap changed. Only call `applyColormap` when either changes. Use `useEffect` instead of `useFrame` for the colormap application:
   ```typescript
   useEffect(() => {
     applyColormap(vertexData, colormap, colorBuffer);
     if (clonedGeometry.attributes.color) {
       (clonedGeometry.attributes.color as THREE.BufferAttribute).needsUpdate = true;
     }
   }, [vertexData, colormap]);
   ```
   This runs only when the segment changes (timeline scrub) or colormap changes, not every frame.

8. Render:
   ```tsx
   <mesh geometry={clonedGeometry}>
     <meshStandardMaterial
       vertexColors
       roughness={0.6}
       metalness={0.2}
     />
   </mesh>
   ```
   Use `vertexColors` prop on material (this enables `vertexColors: true` in Three.js).

9. Add `useGLTF.preload('/models/brain-fsaverage5-unified.glb')` at module level.

Key constraints:
- Do NOT allocate inside useFrame or useEffect -- the colorBuffer is pre-allocated in useMemo.
- The cloned geometry persists for the component lifetime; only the color attribute data changes.
- No emissive/bloom -- the vertex colors provide the visualization directly.
