### Step-by-step instructions

**A. Commit and push your code to GitHub**

On your local machine:
```bash
cd /path/to/NeuroCut
git add -A
git commit -m "Phase 5: add build/verify scripts"
git push origin main
```

**B. Create a RunPod GPU Pod**

1. Go to https://www.runpod.io/console/pods
2. Click "Deploy" (or "+ GPU Pod")
3. Select **A40 (48GB)** -- cheapest GPU that matches our benchmarks
4. Template: **RunPod Pytorch 2.4** (or any template with Docker + nvidia-container-toolkit)
5. Set volume to at least **20 GB** (for Docker image layers)
6. Click "Deploy"
7. Wait for pod to start (1-2 minutes)

**C. Connect to the pod**

Click "Connect" on your pod, then "Start Web Terminal" (or use SSH if you prefer).

**D. Clone your repo and run the script**

```bash
# Clone your repo
git clone https://github.com/YOUR_USERNAME/NeuroCut.git
cd NeuroCut

# Set your HuggingFace token (required for LLaMA 3.2 gated model)
export HF_TOKEN=hf_YOUR_TOKEN_HERE

# Make the script executable and run it
chmod +x scripts/build_and_verify.sh
bash scripts/build_and_verify.sh
```

**E. What to expect**

- Docker build takes **10-20 minutes** (downloading PyTorch, TRIBE v2, etc.)
- Verification script runs 23 checks -- all critical checks should PASS
- Model load test downloads weights from HuggingFace (~5-10 min first time)
- Total time: approximately **20-40 minutes**

**F. Capture the results**

1. Copy the full terminal output (the script prints a structured summary at the end)
2. Come back here and paste the output
3. Note any failures or unexpected results

**G. Stop the pod**

After capturing results, stop the pod to avoid charges:
- Click "Stop" on the pod in RunPod console
