```python
def robust_normalize(
    array: np.ndarray,
    axis: int | None = None,
    percentile: int = 99,
    clip: bool = True,
    two_sided: bool = True,
) -> np.ndarray:
    hi = np.percentile(array, percentile, axis=axis, keepdims=True)
    if two_sided:
        lo = np.percentile(array, 100 - percentile, axis=axis, keepdims=True)
    else:
        lo = np.min(array, axis=axis, keepdims=True)
    denom = hi - lo
    denom = np.where(denom == 0, 1.0, denom)  # prevent division by zero
    out = (array - lo) / denom
    if clip:
        out = np.clip(out, 0, 1)
    return out
```

In the `postprocess` function, apply normalization AFTER `align_to_stimulus` but BEFORE windowing and region scoring:

```python
aligned = align_to_stimulus(predictions)
aligned = robust_normalize(aligned)  # normalize to 0-1 before all downstream
```
